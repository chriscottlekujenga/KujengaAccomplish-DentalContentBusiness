# KujengaAccomplish Dental Content Business

Source of truth for the AI-operated, RDH-reviewed oral-care education business.

## What this is

A faceless, AI-run consumer oral-health education brand that teaches people (mainly parents and teachers) how to take care of their teeth. AI builds and runs the website, blog, Pinterest, Etsy/TPT listings, email funnel, and analytics. A Registered Dental Hygienist named Jessie reviews the content once a week for clinical accuracy. The owner invokes one 5-minute Accomplish session per day.

## How to run a session

Open Accomplish and give one command from the daily queue in `PLAN.md`:

```text
Week 1, Day 1: build the brand brief, pick the domain, draft the first 2 pillar posts.
```

Or start the accelerated sprint:

```text
Start accelerated sprint – Day 1
```

## Money target

$1,000/month net consistently. Standard path reaches it in months 5-6. Accelerated path reaches it in month 4.

## Roles

| Role | Time | What they do |
|------|------|--------------|
| Owner (you) | ~5 min/day | Open Accomplish, run the daily command, approve spend/delete actions |
| Jessie (RDH) | ~60-90 min/week | Review the weekly packet for clinical accuracy |
| Accomplish | Everything else | Research, content, design, listings, pins, email, analytics, optimization |
